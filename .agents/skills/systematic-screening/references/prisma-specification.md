# PRISMA 2020 Specification Reference

## PRISMA 2020 Checklist

### Identification
- [ ] **#1** — Identify as a systematic review (in title)
- [ ] **#2** — Report the research question with PICO components
- [ ] **#3** — Describe the eligibility criteria
- [ ] **#4** — Describe information sources (databases, registers, etc.)
- [ ] **#5** — Specify the date range of the search
- [ ] **#6** — Provide full search strategy for at least one database

### Screening
- [ ] **#7** — State the process for selecting studies (screening, eligibility)
- [ ] **#8** — Describe method of data extraction (forms, processers, piloting)
- [ ] **#9** — List all data items sought (PICO, effect measures)
- [ ] **#10a** — Describe methods for assessing RoB
- [ ] **#10b** — Describe methods for additional analyses (subgroup, sensitivity)

### Results — Study Selection
- [ ] **#11** — Give numbers of studies screened, assessed, included with reasons
- [ ] **#12** — Present characteristics of included studies
- [ ] **#13a** — Present RoB assessments for each study
- [ ] **#13b** — Present results of additional analyses

### Results — Synthesis
- [ ] **#14** — Present results of each meta-analysis done (forest plot)
- [ ] **#15** — Present assessments of certainty (or confidence) in body of evidence

### Discussion
- [ ] **#16** — Provide interpretation of results considering other evidence
- [ ] **#17** — Discuss limitations at study and outcome level
- [ ] **#18** — Discuss implications for practice and research

### Other
- [ ] **#19** — Provide registration information
- [ ] **#20** — Describe sources of funding

## Exclusion Reason Categories

Common exclusion reason categories for PRISMA reporting:

1. **Wrong population** — Study population does not match inclusion criteria
2. **Wrong intervention/exposure** — Intervention or exposure not relevant
3. **Wrong comparison** — No appropriate comparator
4. **Wrong outcome** — Does not report outcomes of interest
5. **Wrong study design** — Study design not eligible (e.g., editorial when RCT needed)
6. **Wrong language** — Not in specified language
7. **Wrong publication type** — Conference abstract, dissertation, etc.
8. **Duplicate** — Already included from another database
9. **No full text available** — Could not obtain full text
10. **Retracted** — Paper has been retracted
11. **Insufficient data** — Cannot extract required data
12. **Wrong timeframe** — Published outside date range

## PRISMA-S (for Literature Search)

Additional reporting items specifically for the search strategy:

- **Search strategies**: Full Boolean logic for each database
- **Databases searched**: Complete list with platform names
- **Date of search**: Exact date for each database
- **Search filters used**: Any pre-defined filters (e.g., Cochrane RCT filter)
- **Supplementary search methods**: Hand-searching, citation tracking, contact with authors
- **Search peer review**: Whether search strategy was peer-reviewed (PRESS checklist)
- **Total records**: Per database and combined
- **Deduplication method**: How duplicates were identified and removed
- **Search update**: Whether and how the search was updated
